# D&D 5e Quick Reference — rus

Russian localization of [**mfriik/dnd5e-quickref**](https://github.com/mfriik/dnd5e-quickref).

> **Tip:** If the page looks off or you are not seeing the newest features, hard-refresh (`Ctrl + Shift + R` / `Ctrl + F5`). The app also auto-reloads when a new version is detected.

---

## What this fork is

A compact, browser-friendly quick reference for *Dungeons & Dragons 5e* (both **2014** and **2024** rulesets), fully translated into Russian.

- UI, settings, and all rule cards are in Russian
- Terminology follows the [**TTG Club**](https://new.ttg.club/glossary) glossary (e.g. *Рывок*, *Отход*, *Засада*, *Лежащий ничком*, *провоцированная атака*)
- Defaults to the **2024** ruleset (can still switch back to 2014)
- Behavior and structure of the original project are preserved

**Upstream:** [mfriik/dnd5e-quickref](https://github.com/mfriik/dnd5e-quickref)

## Features (inherited)

- Lightweight static HTML/CSS/JS
- Collapsible sections and items
- Optional & homebrew rule toggles
- Instant switch between 2014 and 2024 rules
- Printer-friendly layout

---

## Editing

Rule content lives in the `js/` folder:

| Ruleset | Files |
|--------|--------|
| 2014 | `js/data_*.js` |
| 2024 | `js/2024_data_*.js` |

Edit those files and reload the page — no build step.
